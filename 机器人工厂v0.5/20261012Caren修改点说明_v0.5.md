# 机器人工厂 v0.5 修改点说明

> 2026-10-12 · 修订人：Caren Sze
> 基础：`机器人工厂v0.4`
> 本次交付：`机器人工厂v0.5/` 整包（可直接 `npm run dev` 运行），v0.4 未改动

## 一、变化概览

| 项目 | v0.4 | v0.5 |
| --- | --- | --- |
| 角色类型 | 猫、鸭子、英雄 | 飞天猫、小鸭子、小螃蟹；英雄类型及其素材移除（素材未开源） |
| 切换方式 | 只能靠导入图片或说出物种词 | 舞台左上角新增 Flying Cat / Duck / Crab 切换按钮 |
| 小鸭子 | 原创卡通造型，按部件拼装 | 直接显示示例图里的真实图片，4 款配色切换 |
| 小螃蟹 | 无 | 真实图片，3 种姿态 × 8 款颜色（纯色、渐变） |
| 送去仿真 | 模板来自识别结果 | 模板取舞台上当前的类型（识别结果作为后备），新增 `crab` |
| 右侧场景 | 角色占满窗口 | 角色缩小；新增放大按钮，可铺满工厂页 |

## 二、工厂页（sketch2sim/机器人工厂_v0.5.html）

- **切换按钮**：舞台左上角三个按钮，选中项为深色底加黄色图标。点击后切到该类型的编辑造型；如果舞台正在显示导入的图片，会切回编辑造型。手机宽度下只显示图标。
- **图片类型**：小鸭子和小螃蟹的舞台、右侧仿真预览、收藏缩略图都显示真实图片，图片已去背景并内嵌在 html 里（约 230 KB）。性格标签的待机动作同样作用在图片上。
- **小鸭子**：左侧分类为颜色、性格、标签、口头禅、电量；颜色栏是 4 款图片。
- **小螃蟹**：左侧分类多一个「样式」（3 种姿态）。颜色栏 8 款：纯色 5 款（红为原图）、渐变 3 款（从左到右）。除红色外均为程序换色生成，不是官方配色。
- **场景窗口**：右侧场景里的角色缩小（高度约为场景的 30%，宽度不超过 42%），突出场景本身，不再和中间舞台的大图重复。
- **场景放大**：场景窗口右下角新增放大按钮，点击后场景铺满工厂页，飞、抓、爬、跳舞四个任务按钮浮在底部可直接点；右上角按钮或 Esc 键关闭。
- **随机按钮**：图片类型下随机选款式、颜色、性格和口头禅。
- **任务**：图片类型的飞、抓、爬、跳舞四个任务不设部件条件。
- **导出配置**：`species` 为 `cat` / `duck` / `crab`；`parts` 小鸭子为 `look`，小螃蟹为 `look`、`tint`；`color.body` 为当前款式或颜色的主色。
- **导入图片抠图**：靠得很近的几块（例如和身体分开的钳子、分笔画的线条）合并为同一个角色，不再被拆成多个配色。
- 移除英雄类型的绘制代码、图标和选项，以及 v0.4 中小鸭子的卡通造型。

## 三、外框与桥接

- `preview-harness/factory-bridge.js`：物种词识别改为猫、鸭、螃蟹；送去工厂时模板取工厂页当前类型，识别结果作为后备；确认弹层的物种名新增「小螃蟹」。
- `builder-web/app.js`：模板表新增 `crab`（小螃蟹），需 asset-builder 支持。
- `builder-web/index.html`：去掉入口栏下方的提示文字，以及页脚右侧的"故事可以自由想象，实验如实展示结果。"。
- `style.css`、`server.js` 与 v0.4 相同。

## 五、测试

Playwright（Chromium，外框 + iframe 全链路）：
- 切换按钮：三种类型切换后左侧分类、选项栏、舞台和仿真预览正确。
- 小鸭子选第 2 款、小螃蟹选第 3 种姿态加蓝色，导出配置正确；送去工厂后构建请求为 `template: "crab"`、`body_color: "#2F7BEA"`，确认弹层显示"小螃蟹……蓝色的"。
- 小螃蟹 3 种姿态 × 8 款颜色全部渲染，截图见 `机器人工厂v0.5_不上传素材/预览图/小螃蟹配色/`。
- 场景放大：打开后画布随窗口放大，任务可执行，关闭后恢复原尺寸。
- 飞天猫回归（标签、口头禅、电量、待机动画、撤销、收藏、嵌入通信）通过；无 JS 报错。
