# 机器人工厂 v0.5 · 性格接轨与三种编辑界面说明

> 2026-10-12 · 修订人：Caren Sze
> 适用：`机器人工厂v0.5`（`sketch2sim/机器人工厂_v0.5.html` + `builder-web` + `preview-harness/factory-bridge.js`）

## 一、性格如何与仿真接轨

### 1. 性格先变成四个数值

孩子有三种方式设定性格，最后都换算成同一组 0–1 的数值：速度（speed）、弹跳（bounce）、胆量（bold）、好奇（curious）。

| 输入方式 | 换算方法 |
| --- | --- |
| 选性格预设（Lively / Calm / Shy / Brave） | 直接取预设值，例如 Lively = 速度 .82、弹跳 .90、胆量 .62、好奇 .78 |
| 选性格标签（最多 3 个） | 每个标签对应一组数值，多个标签取平均 |
| 说一句话或打字描述 | 按关键词加减（如"快""勇敢""好奇"），带"非常、超级"等程度词时幅度放大 1.45 倍，结果限制在 .06–.96 |

反过来，数值变了也会自动推回最接近的标签（与标签的距离小于 0.22 的才算），所以标签和数值始终一致。

### 2. 在工厂页的仿真预览里（已实现）

右侧仿真视图和中间舞台直接用这四个数值驱动动作：

| 数值 | 影响 |
| --- | --- |
| 速度 | 任务完成快慢（任务时长 × (1.42 − 速度 × 0.68)）；待机弹跳的节奏；音效音高 |
| 弹跳 | 待机和走路时上下弹跳的幅度；眨眼频率 |
| 胆量 | 胆小的做任务时轨迹会摇晃，待机时身体略向后倾；任务成功时胆量 > 0.7 露出獠牙笑，失败时胆量 < 0.35 会哭 |
| 好奇 | 待机时左右张望的幅度；飞天猫的头部歪斜角度 |

舞台上还按标签播放待机动作：Lively 小跳、Calm 慢呼吸、Shy 缩小加颤抖、Brave 挺胸、Curious 歪头。小鸭子、小螃蟹和导入图片都是图片上台，这些动作同样作用在图片上。

### 3. 传给 Spark 构建台（已实现）

工厂页通过 postMessage 把完整配置交给外框的构建台：构建台发 `unbound:request-config`，工厂页回 `unbound:concept-config`，此后配置有变化会自动推送。性格部分的格式：

```json
"personality": {
  "tags": ["brave", "curious"],
  "mood": "custom",
  "traits": { "speed": 0.62, "bounce": 0.40, "bold": 0.78, "curious": 0.64 }
}
```

孩子点「送去工厂真正造出来」时，`unbound:build-request` 里的 `cfg` 也带着这些字段。

### 4. 进入真实仿真（Isaac Sim）：还没接上

目前送进真实构建的只有角色模板、机身颜色、整体缩放和场景。asset-builder 会拒绝未知字段，所以性格数值到了构建台就停住了，构建台页面上也写明了"性格标签暂未映射，不会进入真实构建"。

下面两种接法都需要和 Rosy 确认，参数名以后端实际支持的为准：

| 方案 | 做法 | 需要后端改什么 |
| --- | --- | --- |
| A. 写进需求文字 | 构建台生成需求时加一句，如"性格：勇敢、好奇；动作偏快、少弹跳"，交给流水线里的「表情与头部」阶段由模型理解 | 不改契约；效果取决于模型怎么理解这句话 |
| B. 结构化字段 | 新增 `design.personality.traits`，在仿真里映射成具体参数，例如速度 → 移动或推力上限，弹跳 → 步态起伏，胆量 → 接近障碍物的距离，好奇 → 头部转动频率 | asset-builder 和仿真脚本都要支持新字段 |

我的建议是路演前先用方案 A，零契约改动；方案 B 作为之后的正式接法。

## 二、飞天猫、小鸭子、小螃蟹三种编辑界面

### 1. 怎么切换

| 来源 | 判断依据 | 生效方式 |
| --- | --- | --- |
| 舞台左上角切换按钮（v0.5 新增） | 点 Flying Cat / Duck / Crab | 立即切换，并回到该类型的编辑造型 |
| 「画给它看」导入图片 | 本地看图模型返回的 `creature` 字段 | 桥接脚本写进 `cfg.species`，扫描结束后切换，舞台先显示导入的图片 |
| 「说出来」或打字 | 句子里的物种词：猫/cat → 飞天猫；鸭/duck → 小鸭子；螃蟹/蟹/crab → 小螃蟹 | 桥接脚本调用 `window.RF_SET_SPECIES` 立即切换 |
| 开发调试 | `window.RF_SET_SPECIES("cat" \| "duck" \| "crab")` | 立即切换 |

默认是飞天猫。切换会记入撤销历史。没有本地看图模型时，导入图片不会自动切换类型，切换按钮、说话和打字仍然有效。

### 2. 三种编辑界面的区别

性格、标签、口头禅、电量四项三种界面通用，下表只列各自不同的部分。

| | 飞天猫 | 小鸭子 | 小螃蟹 |
| --- | --- | --- | --- |
| 舞台上的角色 | 程序绘制的卡通造型，按部件拼装 | 真实图片 | 真实图片 |
| 专属分类 | 身体、耳朵、翅膀、爪子、尾巴、表情、颜色 | 颜色 | 样式、颜色 |
| 选项 | 身体 4 种、耳朵 4 种、翅膀 4 种、爪子 4 种、尾巴 4 种、表情 8 种，颜色 8 组 | 4 款配色，对应示例图里的 4 只 | 样式：3 种姿态（侧面、低角度、正面拿卡片）；颜色：8 款，见下 |
| 任务条件 | 飞要翅膀，抓要肉垫爪或尖爪，爬要长尾或蓬尾 | 不限 | 不限 |
| 送去仿真的模板 | `flying_cat` | `duck` | `crab` |

小螃蟹的 8 款颜色：

| 类型 | 款式 |
| --- | --- |
| 纯色 | 红（原图）、蓝、黄、绿、紫 |
| 渐变（从左到右） | 黄→粉、青→蓝、绿→紫 |


切换后左侧分类、下方选项栏、舞台、右侧仿真预览、收藏缩略图一起换。导出配置带 `species`；小鸭子的 `parts` 为 `look`（第几款），小螃蟹为 `look`（姿态）和 `tint`（颜色）。

### 3. 送去仿真

选好后点「送去工厂真正造出来」，确认弹层会说出类型和颜色（如"你的小伙伴是一只小螃蟹！蓝色的……"），确认后构建请求带上模板和机身颜色，例如：

```json
{ "design": { "scene": { "scene_id": "meadow" },
              "asset": { "scale": 1, "body_color": "#2F7BEA", "template": "crab" } } }
```

后端目前只确认支持飞行猫模板；`duck` 和 `crab` 需要 asset-builder 新增或确认，才能真正造出来。
