# 机器人工厂 v0.4 · 性格接轨与三种编辑界面说明

> 2026-10-11 · 修订人：Caren Sze
> 适用：`机器人工厂v0.4`（`sketch2sim/机器人工厂_v0.4.html` + `builder-web` + `preview-harness/factory-bridge.js`）

## 一、性格如何与仿真接轨

### 1. 性格先变成四个数值

孩子有三种方式设定性格，最后都换算成同一组 0–1 的数值：速度（speed）、弹跳（bounce）、胆量（bold）、好奇（curious）。

| 输入方式 | 换算方法 |
| --- | --- |
| 选性格预设（Lively / Calm / Shy / Brave） | 直接取预设值，例如 Lively = 速度 .82、弹跳 .90、胆量 .62、好奇 .78 |
| 选性格标签（最多 3 个） | 每个标签对应一组数值，多个标签取平均 |
| 说一句话或打字描述 | 按关键词加减（如"快""勇敢""好奇"），带"非常、超级"等程度词时幅度放大 1.45 倍，结果限制在 .06–.96 |

反过来，数值变了也会自动推回最接近的标签（与标签的距离小于 0.22 的才算），所以标签和数值始终一致。

### 2. 在工厂页的仿真预览里（已实现）

右侧仿真视图和中间舞台直接用这四个数值驱动动作：

| 数值 | 影响 |
| --- | --- |
| 速度 | 任务完成快慢（任务时长 × (1.42 − 速度 × 0.68)）；待机弹跳的节奏；音效音高 |
| 弹跳 | 待机和走路时上下弹跳的幅度；眨眼频率 |
| 胆量 | 胆小的做任务时轨迹会摇晃，待机时身体略向后倾；任务成功时胆量 > 0.7 露出獠牙笑，失败时胆量 < 0.35 会哭 |
| 好奇 | 待机时左右张望的幅度；飞天猫的头部歪斜角度 |

舞台上还按标签播放待机动作：Lively 小跳、Calm 慢呼吸、Shy 缩小加颤抖、Brave 挺胸、Curious 歪头。导入图片直接上台时，这些动作同样作用在图片上。

### 3. 传给 Spark 构建台（已实现）

工厂页通过 postMessage 把完整配置交给外框的构建台：构建台发 `unbound:request-config`，工厂页回 `unbound:concept-config`，此后配置有变化会自动推送。性格部分的格式：

```json
"personality": {
  "tags": ["brave", "curious"],
  "mood": "custom",
  "traits": { "speed": 0.62, "bounce": 0.40, "bold": 0.78, "curious": 0.64 }
}
```

孩子点「送去工厂真正造出来」时，`unbound:build-request` 里的 `cfg` 也带着这些字段。

### 4. 进入真实仿真（Isaac Sim）：还没接上

目前送进真实构建的只有机身颜色、整体缩放、角色模板和场景。asset-builder 会拒绝未知字段，所以性格数值到了构建台就停住了，构建台页面上也写明了"性格标签暂未映射，不会进入真实构建"。

下面两种接法都需要和 Rosy 确认，参数名以后端实际支持的为准：

| 方案 | 做法 | 需要后端改什么 |
| --- | --- | --- |
| A. 写进需求文字 | 构建台生成需求时加一句，如"性格：勇敢、好奇；动作偏快、少弹跳"，交给流水线里的「表情与头部」阶段由模型理解 | 不改契约；效果取决于模型怎么理解这句话 |
| B. 结构化字段 | 新增 `design.personality.traits`，在仿真里映射成具体参数，例如速度 → 移动或推力上限，弹跳 → 步态起伏，胆量 → 接近障碍物的距离，好奇 → 头部转动频率 | asset-builder 和仿真脚本都要支持新字段 |

我的建议是路演前先用方案 A，零契约改动；方案 B 作为之后的正式接法。

## 二、导入飞天猫、鸭子、奥特曼，切换三种编辑界面

### 1. 怎么触发切换

| 来源 | 判断依据 | 生效方式 |
| --- | --- | --- |
| 「画给它看」导入图片 | 本地看图模型返回的 `creature` 字段 | 桥接脚本把它写进 `cfg.species`，扫描动画结束后切换 |
| 「说出来」或打字 | 句子里出现物种词：鸭/duck → 鸭子；奥特曼/超人/英雄/hero → 英雄；猫/cat → 飞天猫 | 桥接脚本调用 `window.RF_SET_SPECIES` 立即切换 |
| 开发调试 | 手动调用 `window.RF_SET_SPECIES("cat" \| "duck" \| "hero")` | 立即切换 |

默认是飞天猫。切换时会记入撤销历史，点撤销能回到切换前。没有本地看图模型时，导入图片不会自动切换物种，说话和打字里的物种词仍然有效。

### 2. 三种编辑界面的区别

性格、标签、口头禅、电量、颜色这五项三种界面通用，下表只列各自专属的部分。

| | 飞天猫 | 鸭子 | 奥特曼（英雄类型） |
| --- | --- | --- | --- |
| 专属分类 | 身体、耳朵、翅膀、爪子、尾巴、表情 | 身体、嘴巴、眼睛、翅膀、脚 | 身体、头盔、面罩、披风、靴子、胸章 |
| 选项 | 身体：圆、瘦长、敦实、四足；翅膀：五刃、三刃、蝙蝠、无；表情 8 种等 | 身体：圆、高、胖；嘴巴：扁、圆、张大；眼睛：镜头、圆点、眯眼、星星；翅膀：小、大、无；脚：蹼、靴子、轮子 | 身体：强壮、修长、迷你；头盔：天线、圆顶、耳舱；面罩：横条、双镜、屏幕脸；披风：短、长、无；靴子：喷气、普通、轮子；胸章：星、闪电、心 |
| 任务条件 | 飞要翅膀，抓要肉垫爪或尖爪，爬要长尾或蓬尾 | 飞要小翅膀或大翅膀，抓要扁嘴或张大嘴，爬要蹼或靴子 | 飞要喷气靴，抓不限，爬要普通靴或轮子 |
| 左上角图标 | 猫脸 | 鸭头 | 头盔 |

切换后左侧分类、下方零件栏、舞台、右侧仿真预览、收藏缩略图、任务卡的判断条件都一起换。导出配置会带上 `species`，`parts` 只输出当前类型的部件。

### 3. 导入图片后舞台显示什么

- 导入的图片自动去背景后直接站上舞台，右侧仿真预览同步显示，三种类型都一样。
- 图里有多个角色时只放第一个，其余在「颜色」分类里作为配色切换：鸭子示例图 4 款，奥特曼示例图 9 款。
- 孩子在零件栏换了部件（颜色、电量除外），舞台切到该类型的可配置造型，方便看到改动；点舞台右下角的原图小卡片可以切回原图。
- 可配置造型是原创卡通形象。送去真实构建时，后端目前只认飞行猫和鸭子模板，英雄类型会退回飞行猫，需要后端新增模板。
