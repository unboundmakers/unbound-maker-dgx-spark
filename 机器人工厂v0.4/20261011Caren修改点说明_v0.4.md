# 机器人工厂 v0.4 修改点说明

> 2026-10-11 · 修订人：Caren Sze
> 基础：`机器人工厂v0.3`（外框入口栏 + 桥接 + 内页）
> 本次交付：`机器人工厂v0.4/` 整包（可直接 `npm run dev` 运行），v0.3 未改动

## 一、变化概览

| 项目 | v0.3 | v0.4 |
| --- | --- | --- |
| 中间工厂页视觉 | 沙黄色块，扁平填充 | 暖白底、淡网格、桃色/蜜黄/杏色光晕，面板为半透明磨砂玻璃，细线图标；选中项为深色底加黄色图标（v0.3.3 预览方案） |
| 角色类型 | 只有飞行猫 | 猫、鸭子、英雄三种，由「画给它看」的识别结果或孩子说/打的词决定 |
| 导入的图片 | 只作为舞台右下角的参考小卡片 | 抠图后直接作为舞台角色和仿真预览中的角色；图里有多个角色时只放一个，其余在颜色分类里作为配色切换 |

## 二、视觉（sketch2sim/机器人工厂_v0.4.html、builder-web/style.css）

- 工厂页底色 `#FCF9F4`，叠加淡暖棕网格和三团暖色光晕；外框 iframe 底色同步改为 `#FCF9F4`。
- 分类、舞台、零件栏、场景、任务卡、工具栏为半透明磨砂玻璃（`backdrop-filter`），白色高光边、暖色柔和阴影。
- 图标为石墨灰细线；选中的分类、场景和保存按钮为深色底加黄色图标，和外框「孩子模式」开关同一配色；选中的零件为白底加琥珀色描边和光圈。
- 外框（页头、入口栏）保持 v0.3 不变。

## 三、角色类型切换

- 新增 `SPECIES` 定义，每种角色有自己的分类、选项、默认值和任务条件；性格、标签、口头禅、电量、颜色为通用项。

| 类型 | 专属分类 | 任务条件 |
| --- | --- | --- |
| 猫 | 身体、耳朵、翅膀、爪子、尾巴、表情 | 与 v0.3 相同 |
| 鸭子 | 身体（圆/高/胖）、嘴巴（扁/圆/张大）、眼睛（镜头/圆点/眯眼/星星）、翅膀（小/大/无）、脚（蹼/靴子/轮子） | 飞：有翅膀；抓：扁嘴或张大嘴；爬：蹼或靴子 |
| 英雄 | 身体（强壮/修长/迷你）、头盔（天线/圆顶/耳舱）、面罩（横条/双镜/屏幕脸）、披风（短/长/无）、靴子（喷气/普通/轮子）、胸章（星/闪电/心） | 飞：喷气靴；抓：无限制；爬：普通靴或轮子 |

- 切换时左侧分类、零件栏、舞台、右侧仿真预览、收藏缩略图、左上角图标一起换；撤销可以回到切换前。
- 鸭子和英雄的可配置造型是原创卡通形象，不对应任何品牌产品或角色。
- 手动切换接口：`window.RF_SET_SPECIES("cat" | "duck" | "hero")`。
- 导出配置 `RF_CONFIG()` 新增 `species`，`parts` 按当前类型输出；英雄类型不再输出 `wings`。

## 四、导入图片直接上台

- 「画给它看」导入后，自动去掉与图片边缘相连的纯色背景，被轮廓包住的白色部分（如白色身体）保留；浅色水印按背景处理，角色身上的残留改为纸面底色；小字、零碎斑点不会单独成为角色。
- 图里有多个角色时逐个抠出：舞台只放第一个，颜色分类里列出全部角色作为配色选项，点哪个舞台就换成哪个，界面主色也跟着换成该角色的主色。
- 孩子换了某个部件（颜色、电量除外）时，舞台切回可配置的原创造型；点舞台右下角的原图小卡片可以切回原图。
- 性格标签的待机动作对原图同样生效。

## 五、桥接（preview-harness/factory-bridge.js）

- 物种识别新增英雄：文字或看图结果包含「奥特曼、超人、英雄、战士、hero、ultraman」等词时判定为英雄。
- 看图结果带回的物种写入 `cfg.species`；语音和打字识别到物种时调用 `RF_SET_SPECIES`。
- 确认弹层的物种名新增「英雄机器人」。

## 六、运行

```
cd 机器人工厂v0.4/preview-harness
npm run dev          # 默认 http://localhost:7100
```
`server.js` 与 v0.3 相同，`/factory` 自动取 `sketch2sim` 里版本最高的 html，即 `机器人工厂_v0.4.html`。看图识别物种需要晶晶的本地 Ollama 环境；没有时画画回退到内置简易识别，不会切换物种，打字和说话里的物种词仍可切换。

## 七、测试

Playwright（Chromium，外框 + iframe 全链路）：
- 外框：入口栏打字、说话（模拟转写）、选图、送去构建、建造中按钮置灰、见面仪式，与 v0.3 结果一致。
- 猫：标签、口头禅、电量、待机动画、英文语音示例回归通过。
- 鸭子 / 英雄：用 `机器人工厂可选类型` 文件夹里的两张图导入（看图结果为模拟），类型切换正确，舞台显示单个角色，颜色分类分别出现 4 款和 9 款配色，切换后舞台和仿真预览同步。
- 无 JS 报错；控制台仅有没有本地 Ollama 时识别接口返回的 502。
