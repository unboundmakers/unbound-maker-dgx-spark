# Skill Card

Current source-candidate checks supersede the historical pending items below:
[release scope and limits](../../verification/release-20260929/README.md).
No full behavior verification or NVIDIA certification is claimed.

- Owner: Unbound Maker project team.
- Version: 0.1.0 development.
- Capability: local template composition, character start placement, selective dependency packaging and CPU OpenUSD checks.
- Data access: approved local asset root and character package; writes a new output directory. Production scene builder does not call networks, subprocesses or model APIs. Maintainer snapshot tool imports the explicitly inspected project's moon_rules helper; never run against unknown code.
- Template sources: existing meadow-v0.3 scene work, NVIDIA grass/gravel/astronaut assets, NASA-derived planetary and distant lunar data, user-provided Poly Haven sky and original educational camp assets. Per-source records stay with outputs; no blanket CC0 claim.
- Limits: no arbitrary world generation, live runtime, autonomous character, gait training, rendering guarantee or generic secure USD conversion.
- Verification: CPU suites and build evidence tracked separately; no official certification. Agent A/B evaluation, independent security scan, team signing and live Isaac regression remain separate gates.
- Publishing: Skill archive excludes third-party meshes and textures. Generated local asset packages require per-source licensing review before publication.
