# 架构图与提交范围

输出：[可编辑 SVG](architecture.svg) / [PNG 预览](architecture.png)。不生成 PDF。

图示的是本版真实连接：最小构建网页 → 回环 API → 一个 Builder Agent → 五个 Skill → Spark 上的 Isaac Sim → 结果返回网页。

- 创作端保留孩子和导师确认需求的产品定位；本版只接入受支持的自然语言、配色与参数，并未宣称手绘直接生成完整机器人。
- 资产来源是外部建模或既有授权模板；当前飞行猫只有一个 adapter。
- 本地模型是 Agent 的决策组件，不是五个独立 Agent，也不替代 Blender 或专门的建模工具。
- 故事模式为草地 / 太阳系，实验模式为月球场景中的重力、质量、推力对照。
- 绿色 `Skill` 是模块标记；蓝色为编排与故事路径，橙色为 Runner 和实验路径，虚线为后续工作。颜色不表示 NVIDIA 认证。
- 图中的 92 项是每个平台的模块回归数量，不是模型成功率；提示词对照没有执行工具。
