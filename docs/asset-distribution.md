## 使用者能验证什么

仅下载源码即可运行 Builder 标准库回归和各 Skill 的 `capabilities`。
USD 构建测试还需要授权模板、完整场景目录和兼容解释器。缺少这些前提时
应明确失败，不得临时换成占位图或跳过测试后声称完整复现。

当前 Asset / Personality 适配器绑定 `flyingcat-v1` 的骨骼和哈希。
另一只通用机器人不能直接改名替换，需独立 adapter 及对应测试。
这是后续工作，不在本次源码预览中伪装成已完成。

## 维护者发布规则

只从新的源码候选目录打包，不从 `artifacts/`、运行数据库或旧 Skill ZIP 取文件。
源模型不删除、不改许可、不随源码归档；单独扫描所有归档文件列表。
团队签名只覆盖冻结源码和证据的完整性，不给外部资产追加授权。
